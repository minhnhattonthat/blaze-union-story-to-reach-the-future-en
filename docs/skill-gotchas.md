# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- references/platform-psp.md: `cpk.py` refuses ITOC-only CPKs (no names, numeric IDs, no TOC), which CRI also ships; this repo wrote a reader with a CRILAYLA decoder in `tools/itoc.py`, worth adopting.
- references/platform-psp.md: EBOOT dump via `DumpFileTypes` works only in the windowed build, PPSSPPHeadless ignores it; and Vulkan's default failed silently (only `FailedGraphicsBackends.txt` as evidence), `GraphicsBackend = 2` fixed it.
- references/emulator-qa.md: psp.py runs write `ppsspp.log`, not the `log.txt` emu.py's help describes.
- references/emulator-qa.md: PPSSPP WebSocket memory breakpoints work from Python: `memory.breakpoint.add` then `cpu.runUntilTime` + `wait("cpu.stepping")`; `cpu.getAllRegs` categories[0].uintValues gives GPRs. See `tools/debug/ppdbg.py`. No skill tool wraps this.
- references/graphics.md: a sweep at 240x136 per cell loses 8-px text strips entirely, and PTX-style slices can share the previous texture's palette (offset 0): noise until handled.
- SKILL.md: a dispatched worker told "no subagents" has no cheap way to read a 100-page sweep; the sheet budget alone forces a hand-back. Worked here: quarter-size overviews (4 pages per image) to classify, then crops of text regions at full size: roughly 60k tokens instead of 180k (estimated from image sizes), at the cost of small text on quarter-size pages being easier to miss.
- scripts/psp.py: `WS.recv` hands a WebSocket close frame (opcode 8) to `json.loads`, so an emulator that dies shows as `UnicodeDecodeError ... byte 0xe9` (status 1001 = `03 E9`), which reads like a text bug. It should raise a clear "emulator closed the connection".
- references/platform-psp.md: PRX `lui` values can be segment-relative: here values below 0x0A are relative to segment 1 (vaddr 0x2BFCA0), so RAM = load base + segment base + value. A plain `base + value` read returned a plausible wrong word and cost a failed warp.
- scripts/psp.py: `cpu.status` `us` is ticks / clockHz, so when a game calls `scePowerSetClockFrequency` (here 222 to 266 MHz at battle start, and back) `us` jumps. `Run.run_to` then sits in its `us < target` loop waiting for a stop that already came: a 30 s socket timeout in `warp.py`, `emu.py` and `play.py` (`emu.py exit 2`), at the first battle. Fix (kept repo-local in `tools/debug/warp.py`, which covers the debug tools, not emu.py and play.py): clear queued events, one wait after `runUntilTime`, and if `clockHz` changed add `us - ticks * 1e6 / old clock` to `self.base`. Needed in psp.py before any route passes a battle start.
- references/emulator-qa.md: PPSSPPHeadless ends without any log line on a bad guest access (kernel shutdown, close frame). Finding the spot: breakpoints after every `jal` in a range, printed in hit order, drill into the last call (`tools/debug/crashpc.py`). Instruction stepping does not help: it hops between threads.
- references/emulator-qa.md: a "crash on warp" can be the warp's data, not the warp: two stage records point at script entries that are null in the file, and the game-over text index is 0 when no battle set it. Check the data the crash path reads before suspecting setup.
- references/emulator-qa.md: `play.py SESSION --rom ROM --state S` takes no presses on the creating call; create the session first, then press. Copying a state into a hand-made session folder cold-boots instead.
- references/emulator-qa.md: look for a game's table of stages early: here a 153-record table with script and card ids plus names like `1_02_A`, found from a save-description string, and a leftover start path in the re-init mode, gave warps with no story flags.
- references/graphics.md: text that looks cut in half across a sweep may be a packed atlas, not a decoder bug. Here PTX slices lay a sprite's lower half beside its upper half and a PTG cell table reassembles them; a worker misread one such strip as two lines. Check for a cell table in front of the texture before reading strips.
- references/platform-psp.md: ITOC repack: `tools/itoc.py rebuild` regenerates the ITOC byte-exact and moves rows from the u16 L table to the u32 H table when a file reaches 64K; `cpk.rebuild`'s in-place row patching could not do that, and 46 of this game's 57 scripts start in the L table. Engine reads raw-stored files in place of every compressed one here, so no CRILAYLA encoder was needed. Worth adopting beside the reader.
- references/pipeline.md §Identity: a disc identity test writes whole images through pytest's `tmp_path`, which keeps the last 3 runs by default: 5.8 GB of a nearly full C: within a few runs. `tmp_path_retention_policy = none` in `pytest.ini` fixed it.
- references/graphics.md: the hook guard also blocks a heredoc that merely holds backslash escapes in a throwaway script, so scratch scripts go through the file-write tool; `| tail` in the same command hides the test exit code from an `echo $?`, redirect to a log instead.
- references/pipeline.md §Recon: find the script VM's handler table before writing a bytecode walker: scan the EBOOT for a run of 200+ code pointers. Here that gave every opcode's flow, inline-text ops and jump tables from the handlers in an hour, after a linear `[op, len]` walk had stopped early in all 57 files. A walker that consumes a whole 196 KB script with no leftover bytes is good evidence it is right.
- references/platform-psp.md: a PRX's `.rel.*` sections (type 0x700000A0) list every pointer in code and data, hi/lo pairs included, so EBOOT string references can be read rather than searched for. The PPSSPP dump keeps its section headers.
- references/pipeline.md §Extract: a NUL search for string ends breaks on printers whose control codes take arguments: `02 00 28 00` holds zero bytes. Scan with the printer's own code lengths. A message reference can also start partway through a longer message, so records may overlap.
- SKILL.md / harness: `cat > /dev/null` or `python -` with a heredoc in the Bash tool can sit on stdin until the 2-minute timeout; pass `< /dev/null` when a script takes no input.
- references/platform-psp.md: a third PT_LOAD works in PPSSPP for hook code and moved strings, with new jal sites listed in an added `.rel` section (type 0x700000A0, sh_info 1). PPSSPP's ScanForFunctions asserts and closes the debugger if an executable section's end isn't word-aligned.
- references/emulator-qa.md: PPSSPPHeadless closing mid-run shows up in psp.py as a UTF-8 or JSON error, not EOF: a WebSocket close frame (`03 E9`) gets parsed as text. Read it as "the guest crashed or the emulator stopped".
- references/pipeline.md §Extract: pointer-target string scans pick up tables. Exclude any target whose own word carries a relocation (a pointer table), and code tables the printer searches: moving them with the text crashes screens far away from them.
- references/pipeline.md §Marker: a boot arena sized to its one big file hangs on Now Loading when that file grows. Look for the arena sizes before blaming the file's format.
- references/pipeline.md §Width gate: read the fonts' palettes before drawing English pages. Here one sheet is white-on-outline with index 0 clear, one is dark ink with 15 clear and an opaque grey at 0, one is 3 colours and needs unsmoothed glyphs. The marker showed the mismatch at once as grey bars and stray glyphs.
- references/pipeline.md §Width gate: a fill build (every box filled to its window, ending in `|`) also finds stack buffers: a string sprintf'd into 40 bytes ended the emulator. Check any `%s` format for its destination size and carry a byte limit next to the px limit.
- references/pipeline.md §Marker: marker text that looks partly drawn ("r oo") is a routine with its own idea of ASCII, and marker text that replaces a number ("]Theui[B") is a lookup table taken for a string (`０１２３４５６７８９`). Both only show at the marker stage. Also grep for line-break tables beside per-cell layout loops.
- assets/batches.py: per-line ids and voice codes add tokens to every batch line a solo translator reads and writes (not measured); here `show` prints `n|speaker|JP` and output is `n<TAB>EN`. Identical lines are also merged once: unique text is about 12% smaller than the total (453k to 400k JP chars, by text alone; the speaker + window key used here merges less). Worth adopting.
- references/translation.md §Fitting: author `en` with no line breaks and wrap at build and lint from the font's widths (`tools/fit.py`): one code path, so what passes the lint is what prints, and translators never place `{n}`.
- references/pipeline.md §Recon: look for a speaker id in the portrait op before translating: here op EB's u16 at +8 indexes the 12-byte name table, which tagged 12,105 of 12,519 event lines, 97% (`tools/speakers.py`; FCT 3/15 children mostly get none). Speakers aren't in the text at all, so translators and reviewers would otherwise guess.
- SKILL.md: a run brief of "no subagents" makes phase 6 a chain of workers. Estimate, not measured: about 12 to 15 batches of 3,500 JP characters per worker before the 150k hand-back, so 142 batches left means about 10 more workers. The first worker did 4, the rest of its context went on setup.
- SKILL.md: phase 6 chain, measured: one worker translated 30 batches (b039 to b068, 2,209 records) in one context before handing back, about 2x the earlier estimate of 12 to 15. `check && merge` of several batches at once skips all of them when one fails: re-merge the earlier ones with the fix.
- SKILL.md: phase 6 chain, second measure: one worker translated 31 batches (b106 to b136, 3,721 records) before handing back, so about 30 batches per worker holds. Some FCT bark records are byte slots, not windows; the check names them.
- references/translation.md: check that every batch with an .out.tsv was merged: 20 batches here had output and passed check but never reached script/, found only by counting empty records per batch; a status line said they were done.
- references/translation.md: under a no-subagent brief with codex out of credits the reviewer pass falls back to a self-review, which is weak and sampled; plan the codex budget for 12 chunks before phase 6 ends.
- references/pipeline.md: a batch line's key holds the window, so one JP with two windows needs two lines; shortening one (stage title) leaves the twin (chronicle title) long, and merge reports success.
references/pipeline.md: a translator-facing "window unknown, use the Japanese width" default is not safe for layout: the build wraps at that width too, so short names and game over lines wrapped and lost rows. Trace every pointer table to its print site (Blaze Union tools/debug/softwin.py) before the first full build.
references/pipeline.md: an extractor class for "printf logs" (ASCII newline in the string) can hide player text: Blaze Union's save details are sprintf formats with newlines for the system dialog. After classing, list the class's strings that code references and read them.
- references/pipeline.md: a window's row count can be set in three places on one screen (lay-out call, per-frame fade, and the next list's first row number). On Blaze Union the third row was overwritten by the list, not clipped; a shot alone looked like a layout limit. Trace the printer's row arguments first.
- references/graphics.md: packed sprite atlases (blank space cut out, a fixed slice size) hold only as much ink as the Japanese had; English wider or taller than the Japanese ink box overflows them. Keep English to the Japanese ink box and shrink until the repacker accepts it (Blaze Union `gen_gfx.fitted`). Text over symmetric art (terrain diamonds): paste the mirror of the far side over the letters, cleaner than diffusion inpainting, which smears light art.
- references/graphics.md: a lone PTX atlas (no PTG) is cut by rect tables in the EBOOT; search the dump for u16 (x,y,w,h) runs that match the texture's rows (1531's titles: 0x2794E4). The sweep's `index.tsv` sizes are halved for big textures, so take sizes from the renderer, not the index.
- references/pipeline.md: on Windows, a Python script's `print` redirected (`>>`) into a data file writes CRLF; with `eol=lf` git warns and normalises, but the working copy is mixed until `git checkout -- FILE` after the commit.
- references/graphics.md: sprite sheet sizes in a sweep index can be half the real size (PTX scaled in the group): read the decoded image size before computing grid cells, or a right column gets clipped.
- references/graphics.md: a shipped font may lack rating glyphs (☆★); leave the original star in place and redraw only the words around it.
